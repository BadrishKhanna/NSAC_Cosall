# NSAC_Cosall
Cosall is an interactive web application that helps users learn about, plan, and set timelines for lunar missions. Whether an educator is teaching students, an amateur is curious about lunar missions, or and expert looking towards getting a serious, honest first pass for their missions, Cosall satisfies their needs.

Cosall's backend acquires the open source NASA data and presents it according to the user's inputs. This lets the user to know the appropriate timeline, landing site, launch date for their hypothetical mission. The tools Cosall provides are built around one core principle : the horizon visibility (of the Sun and the Earth).

Planning missions to the moon, especially to its south pole is a challenging task and the tools necessary for it are usually unavailable to the general public or are complex. Cosall removes the barriers and enables access to everyone.
